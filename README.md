### 💫 Немного больше

Я — студент и начинающий **Python-разработчик**, увлечённый созданием полезных проектов: от Telegram-ботов до приложений с использованием нейросетей. Учусь в **Люберецком техникуме им. Ю. А. Гагарина**, где осваиваю backend-разработку, базы данных и автоматизацию процессов.

- 🔭 **Сейчас работаю над:** Telegram-ботами, AI-фильтрами для изображений, веб-приложениями
- 🌱 **Изучаю:** нейросетевые фильтры, распознавание лиц, анализ текста, архитектуру ПО
- 💡 **Ценю:** читаемость кода, чистую архитектуру, аккуратный UI/UX
- 🎯 **Цель:** Junior Python / Backend Developer в дружной команде
